## 前提

- キーボード配列は英語（QWERTY）、フランス語（AZERTY）、ドイツ語（QWERTZ）、韓国語、アラビア語から選びます。日本語配列はありません。
- OS は日本語表示に対応しています（公式 FAQ）。
- そのため、日本語は **QWERTY のローマ字入力** で使うことになる見込みです。

## 確認したい IME（日本語入力アプリ）

| IME | 確認ポイント | 結果 |
|---|---|---|
| Gboard（日本語） | 物理キーボードでのローマ字入力、変換候補の選び方、英数との切り替え | 要確認 |
| ATOK for Android | 同上。ハードウェアキーボード向けの設定項目 | 要確認 |
| その他（Mozc ベースのアプリなど） | 同上 | 要確認 |

## 確認項目

### 入力の基本

- [ ] ローマ字で入力して変換できるか
- [ ] 変換候補を物理キー（スペース、矢印、Enter）で選べるか
- [ ] 日本語と英数の切り替え方法（Ctrl+Space、Shift+Space、専用キーなど）
- [ ] 全角と半角、カタカナへの変換方法
- [ ] 句読点（、。）と長音（ー）、「」の入力方法
- [ ] 変換候補が小さい画面（高さが低い）で入力欄を隠しすぎないか

### Android 側の設定

- [ ] 設定 > システム > キーボード > 物理キーボード で、レイアウトを「英語（米国）」にしたときの挙動
- [ ] 物理キーボード接続中にソフトウェアキーボードを表示するかどうかの設定
- [ ] 言語の切り替えショートカットが Clicks 独自のキー割り当てと衝突しないか

### Communicator 固有

- [ ] サイドキーの音声入力が日本語で使えるか
- [ ] キーボード面のタッチスクロールが変換候補の選択に使えるか
- [ ] 記号キー（sym）やショートカットキーで日本語の記号が入力できるか
